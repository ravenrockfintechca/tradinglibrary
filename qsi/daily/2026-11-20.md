### QSI-131｜信息型卖空订单流 (Informed Short-Sale Order Flow)

**分类 / 经济机制键**：equity_short_sale_information / `proprietary_institutional_nonprogram_short_sale_orderflow_negative_future_equity_returns`

**经济机制 / Alpha 理论**：具有私人信息或更强分析能力的机构卖空者可能在负面消息被完全定价前积极卖空。关键是投资者类型及新发生的卖空交易，而非存量空头持仓或借券费。

**公式及原语边界**：ShortShare_t = ObservedShortSaleShares_t / ObservedTotalShares_t。研究原语仅为总卖空成交占比；原论文更强信号是 proprietary NYSE institutional nonprogram short-sale flow，无法由公共聚合成交数据还原。

**信号**：按真实可得的机构非程序卖空成交强度，相对自身历史水平及同业截面标准化；公共总短卖占比只能做不可等价的研究 proxy。

**研究规则与退出**：每日仅用已完成披露的数据，按前一天可见的成交方向构造横截面信号，研究未来 5/20 交易日高卖空强度股票的相对弱势；优先作为多头排除过滤器，不假定可无限借券做空。

**市场 / 周期**：NYSE/US equities; daily classified short-sale trades; 5/20-day horizons

**真实数据输入与来源**：论文需要 proprietary NYSE 按机构账户/程序交易标记分类的逐笔卖空数据；公共 FINRA short volume 是不同覆盖口径、不同披露时钟，不能复制 investor-type attribution。另需 PIT 股票行情、企业事件、退市、借券费。

**参数与预注册检验**：原研究窗口 2000–2004，比较多个形成窗口、流动性分位及行业市值中性；聚合 volume 与 short interest 绝不能互换。

**原始论文与实证（不能当作策略净绩效）**：Boehmer, Jones, Zhang (Journal of Finance, 2008) 基于专有 NYSE 卖空成交，重卖空股票比轻卖空股票未来20交易日风险调整表现低约 1.16%，机构非程序卖空样本下月差约1.43%；历史研究结果不是本期成本后交易回报。

**论文 DOI**：[10.1111/j.1540-6261.2008.01324.x](https://doi.org/10.1111/j.1540-6261.2008.01324.x)；[出版/原始来源](https://business.columbia.edu/faculty/research/which-shorts-are-informed)

### QSI-132｜企业雇佣增长率风险溢价 (Labor Hiring Rate Risk Premium)

**分类 / 经济机制键**：equity_labor_investment / `firm_employee_hiring_growth_labor_adjustment_costs_cross_section_expected_returns`

**经济机制 / Alpha 理论**：企业雇佣扩张是前瞻性投入。较高净雇佣率与较低未来股票风险溢价相关，可能来自企业劳动调整成本与对经济冲击的对冲属性。

**公式及原语边界**：HiringRate_t = (Employees_t - Employees_t-1) / Employees_t-1；必须保持可比较财年、合并口径，不将空缺职位数量当正式员工数。

**信号**：在财报公开日期后，以年度 employee headcount 增长作行业内排序；低招聘率组对高招聘率组未来收益差异做检验。

**研究规则与退出**：在已公开的 10-K 人数信息后每年重建低/高招聘率股票篮子，月度评估持仓；小本金先探索低雇佣率多头，控制 QSI-108 总资产增长与企业生命周期。

**市场 / 周期**：US listed common shares, annual 10-K headcount, monthly cross-section

**真实数据输入与来源**：SEC 10-K Employees 文本/结构化披露、Compustat EMP(许可)、PIT 文件时间、上市/退市和跨年度并购/季节员工调整。

**参数与预注册检验**：年度 hires=(emp-emp_lag)/emp_lag；行业中性；EMP>0；排除无可比口径、重大资产处置造成的假变化；滚动样本外训练评价。

**原始论文与实证（不能当作策略净绩效）**：Belo, Lin, Bazdresch (Journal of Political Economy 2014) 报告企业招聘率每提高10个百分点，平均年风险溢价约下降1.5个百分点；这是研究关联及资产定价结果，不是该规则净利润。

**论文 DOI**：[10.1086/674549](https://doi.org/10.1086/674549)；[出版/原始来源](https://www.journals.uchicago.edu/doi/10.1086/674549)

**成本、融资与容量**：低频股票换手和价差可控性相对较好；中小盘股冲击、数据授权与员工口径清洗是主要障碍，容量需ADV和单股参与率量化。

### QSI-133｜非投资级公司债券动量 (Non-Investment-Grade Corporate Bond Momentum)

**分类 / 经济机制键**：credit_bond_momentum / `high_yield_corporate_bond_past_total_returns_predict_future_bond_returns`

**经济机制 / Alpha 理论**：非投资级债券的历史总收益延续，可能与信用信息逐步反映、市场分割及交易摩擦有关；债券动量与股票动量不能简单划等号。

**公式及原语边界**：FormationReturn_{bond,t} = product_{m in historical completed months}(1+TotalReturn_{bond,m})-1。必须含票息与债券回收、违约和退市总收益。

**信号**：使用非投资级债券既往多个月的完整总回报排序，并研究下一个月可成交报价下的强弱组表现。

**研究规则与退出**：同评级、期限和行业分层，研究过去6个月总收益领先/落后债券下月收益；回测具体形成窗口独立设稳健性格，不称本简化规则为原论文参数。

**市场 / 周期**：US corporate bonds, TRACE/dealer quotes, monthly rebalancing

**真实数据输入与来源**：许可的 TRACE historical quotes/trades 或同等债券级 PIT 数据，CUSIP 对应票息、提前赎回、违约/回收、发行量、评级公布日及清算/融资成本。

**参数与预注册检验**：6个月研究形成期、1个月持有期只是预注册假设；按 IG vs NIG 分层，排除同债券不成交与 stale pricing，交易费由双向 dealer bid/ask 估算。

**原始论文与实证（不能当作策略净绩效）**：Jostova, Nikolova, Philipov, Stahel (Review of Financial Studies 2013) 使用1973–2011期间81,491只美国公司债，1991–2011历史收益的动量价差平均约59bp/月（全部债券），非投资级约192bp/月；不是本期成本后策略结果。

**论文 DOI**：[10.1093/rfs/hht022](https://doi.org/10.1093/rfs/hht022)；[出版/原始来源](https://doi.org/10.1093/RFS/HHT022)

### QSI-134｜美债远期利率风险溢价预测因子 (Cochrane–Piazzesi Treasury Forward-Rate Premium)

**分类 / 经济机制键**：treasury_term_premium_timing / `treasury_one_year_excess_return_tent_shaped_forward_rate_factor_predictability`

**经济机制 / Alpha 理论**：国债一年持有期超额收益可由不同期限初始远期利率的特定线性组合预测，该组合不只是收益率曲线的水平、斜率或曲率。

**公式及原语边界**：CPFactor_t = b0 + sum_{n=1..5}(b_n * f_{n,t})，b_n 必须在过去历史数据上拟合；期末的 1 年 excess bond holding return = realized holding return - 1Y risk-free alternative。

**信号**：使用当时可以观测的 1–5 年远期利率，滚动 OLS 估计一年期未来超额债券收益，并把 out-of-sample forecast 作为风险预算调整的研究因子。

**研究规则与退出**：每月用已公开收益率/远期利率估计信号，研究 2Y–5Y 国债相对1Y现金的敞口及风险预算；仅先生成预测概率和论文复制报告，禁止将样本内 R2 当作收益或交易指标。

**市场 / 周期**：US Treasury zero-coupon yield/forward curve, 1Y horizon, monthly evaluation

**真实数据输入与来源**：Fed Treasury nominal yield curve/GSW 估计、零息收益率/债券持有期回报、真实交易期限及 bid/ask、保证金/融资数据；同日和时区对齐。

**参数与预注册检验**：训练期至少10年、后续扩展窗口或滚动、外推只用旧信息；远期利率估算口径一致，固定曲线建模规范并与Level/Slope/Curvature 对照。

**原始论文与实证（不能当作策略净绩效）**：Cochrane and Piazzesi (American Economic Review 2005) 发现一项 tent-shaped 远期利率因子能预测1–5年美国国债未来一年超额收益，历史样本 R² 最高约0.44；R²不是Sharpe或回报率。

**论文 DOI**：[10.1257/0002828053828581](https://doi.org/10.1257/0002828053828581)；[出版/原始来源](https://pubs.aeaweb.org/doi/10.1257/0002828053828581)

**开源代码 / 代码地位**：[研究工具](https://github.com/lballabio/QuantLib)。可辅助固定收益期限结构计算；原出版社页面另有 Replication Package 链接，尚未在本次运行执行复现与确认文件许可证。。本次五个原语位于 `qsi/research/qsi_2026_11_20.py`，非完整原论文复现。

**成本、融资与容量**：国债大盘通常深度较高，但预测信号可能小于券差、融资、期限错配和冲击；杠杆风险、久期敞口与期限结构模型错误必须实际验证。

**失效、偏差和可访问性风险**：forward yield 数据 vintage、模型过拟合、系数稳定性、收益率曲线拟合质量、税费融资、久期和跨期复利。

**可证伪的样本外回测**：使用有历史 vintage 的 Fed/GSW 曲线、无前视训练 CP 系数，做1年滚动外推，和持有现金/常久期/Level-Slope-Curvature 模型比较；输出净PnL、OOS R²、Sharpe/MDD及久期敞口。

### QSI-135｜共同基金未观测交易收益差 (Mutual Fund Return Gap Persistence)

**分类 / 经济机制键**：fund_manager_selection / `mutual_fund_reported_net_return_minus_stale_disclosed_holdings_replica_return_predicts_future_manager_performance`

**经济机制 / Alpha 理论**：历史已披露持仓所构成的静态复制组合与真实基金报告收益之间的差额，可能反映经理在两次披露之间的交易行为和未观测决策质量。

**公式及原语边界**：ReturnGap_t = R_reported_fund_net_t - [R_previous_public_holdings_replica_t - monthly_expense_fraction_t]；跨日持仓冻结与费用口径必须一致。

**信号**：基金月度报告净值收益减此前已公开持仓复制收益（调整费用），研究连续正回报差基金是否未来仍优于同业及基准。

**研究规则与退出**：按历史披露时点的旧持仓复制每月基金收益，按过去12个月 return-gap 时间均值与稳定性筛选基金，观察未来12个月扣费后超额收益及换手；只用于基金尽调/选择。

**市场 / 周期**：US open-end domestic equity mutual funds, monthly NAV and disclosed holdings

**真实数据输入与来源**：SEC N-PORT 历史公开持仓（早期历史需商业基金数据库）、公开时间、基金 NAV total returns、split/merger/survivorship、当时可用完整持仓、基准回报、费用率和月度真实净回报。

**参数与预注册检验**：过去12个月均值属于研究候选窗口，结合过去3/6个月稳健性；持仓文件公开前不能用于复制，也不得把本月最新仓位倒填。

**原始论文与实证（不能当作策略净绩效）**：Kacperczyk, Sialm, Zheng (Review of Financial Studies 2008) 对1984–2003超过2,500只美国股票基金，发现 return gap 在截面与时间序列有持续性并能预测未来基金表现；未提供本期具体净Sharpe/MDD。

**论文 DOI**：[10.1093/rfs/hhl041](https://doi.org/10.1093/rfs/hhl041)；[出版/原始来源](https://academic.oup.com/rfs/article-abstract/21/6/2379/1572062)

**开源代码 / 代码地位**：[研究工具](https://github.com/pmorissette/bt)。开放组合模拟器，可用于持仓复制；并非原论文数据或经过独立验证的复现，许可证及当前推送状态本期未复核。。本次五个原语位于 `qsi/research/qsi_2026_11_20.py`，非完整原论文复现。

**成本、融资与容量**：基金实际选择存在费率、最低申购、赎回期限、税务、限购和旧持仓基准错配；不能当股票可实时交易策略；基金具体资产与策略 AUM 必须区分。

**失效、偏差和可访问性风险**：历史披露时间与可见仓位错置、基金份额类混淆、幸存者偏差、费用重复扣减、未观测现金/衍生品及公允价值调整，可能将报告误差误认成经理能力。

**可证伪的样本外回测**：按各期N-PORT或披露时点独立重建可见持仓复制，考虑分红、企业行为、现金与费用；样本外滚动挑选并用净值评价下一12个月基金表现，做 Active Share、费用与资金流控制。

**ZTrader / Z-QCC 部署研究架构（未部署）**：SEC N-PORT point-in-time disclosures + fund NAV / share-class master → stale holdings replication → QCC monthly return gap → fund selector and disclosure lag audit
